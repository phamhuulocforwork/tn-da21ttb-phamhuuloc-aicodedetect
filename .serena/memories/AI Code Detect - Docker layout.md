Repo has FastAPI backend at src/backend (Dockerfile, docker-compose.yml), Next.js frontend at src/frontend (Next 15, new Dockerfile needed), and analysis modules at src/src to be mounted at /src into backend. Backend health at /health. Compose plugin missing on user system; advise installing docker-compose-plugin or CLI plugin to enable `docker compose`. For dev: run compose from src/backend. For prod: build both images and set NEXT_PUBLIC_API_URL to backend service URL.
